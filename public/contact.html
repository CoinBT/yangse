버그 신고 / 기능 제안

게임을 이용하면서 발생한 문제를 공개 GitHub 이슈로 남길 수 있습니다. 무엇을 하다가 오류가 났는지, 어떤 화면에서 발생했는지, 기대했던 결과와 실제 결과가 무엇이었는지를 적어주세요. 문제를 재현하는 데 도움이 되는 정보만 보내 주세요.

GitHub에 문의 남기기기존 문의 확인하기
공개 게시판 주의

GitHub 이슈는 누구나 볼 수 있습니다. 닉네임 외의 개인 식별정보, 세션 토큰, 초대 중인 비공개 게임방 코드, 다른 사람의 채팅 기록, 전화번호, 이메일 등을 공개하지 마세요.

문의할 때 적으면 좋은 정보

  1. 사용 환경: PC/휴대폰, 브라우저 종류 및 대략적인 버전
  2. 플레이 모드: 클래식 또는 Host Show!
  3. 문제가 생긴 단계: 방 만들기, 문제 입력, 질문, 정답 판정 등
  4. 문제를 재현할 수 있는 동작과 실제 결과

개인정보 관련 비공개 문의

현재 공개 GitHub 이슈는 개인정보 처리 요청을 비공개로 안전하게 수신하기 적합하지 않습니다. 독립 도메인 및 공개 서비스 운영 준비 과정에서 운영자 공식 연락 이메일을 지정해 이 페이지에 추가해야 합니다. 운영자 개인 메일주소를 임의로 표시하거나 존재하지 않는 지원팀 연락처를 만들지 않았습니다.

정식 광고 심사와 개인정보 정책 확정을 위해서는 비공개 문의 채널 마련이 필요합니다.
