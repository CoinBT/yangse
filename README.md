# 🎭 양세찬 게임 — 호스트형 실시간 웹게임

별도 월 이용료나 데이터베이스 없이 **호스트 PC가 서버가 되어** 최대 12명의 참가자와 관전자를 지원하는 웹게임입니다.
참가자/관전자는 스마트폰과 PC 브라우저에서 접속할 수 있습니다. 게임 중 호스트 PC는 켜져 있어야 합니다.

## 1. 준비 — 호스트 컴퓨터

1. [Node.js](https://nodejs.org/)의 **LTS 버전(18 이상)**을 설치합니다.
2. 압축을 풀고 `start_windows.bat`을 더블클릭합니다. (`node server.js`로 직접 실행해도 됩니다.)
3. 웹브라우저에서 **http://localhost:3000** 을 엽니다.
4. 닉네임을 입력하고 **방 만들기**를 눌러 6자리 방 코드를 만듭니다.
5. 호스트 서버 콘솔은 게임이 끝날 때까지 닫지 마세요.

> npm install이 필요 없습니다! Node.js 기본 내장 모듈만 사용합니다.

## 2. 친구가 다른 집/네트워크에 있다면

로컬 주소 `localhost:3000`은 호스트 본인만 접속할 수 있습니다. 외부 접속을 열려면 터널 프로그램을 사용하면 편리합니다.

1. [Cloudflare cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 설치.
2. 호스트 서버를 실행해 둔 뒤 다른 터미널에서:

   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```

3. 출력되는 **`https://무작위이름.trycloudflare.com`** 주소를 친구들에게 공유합니다.
4. 친구들은 해당 주소를 열어 **방 참가하기** → **6자리 코드 입력** → **참가자/관전자 선택**으로 입장합니다.
5. `start_tunnel_windows.bat`을 이용해도 됩니다. (cloudflared가 PATH에 설치되어 있어야 함.)

Cloudflare Quick Tunnel은 테스트용 무료 임시 URL입니다. 종료 후 주소가 바뀌고 상용 서비스 수준의 가용성을 보장하지 않습니다. 클라우드플레어 서버는 트래픽 연결에 사용하지만, **게임 로직·방 데이터·점수 계산은 호스트 PC**에서 처리됩니다. 인터넷 연결은 필요합니다. 안정적이고 공개적인 대규모 행사에는 정식 터널/도메인과 별도 서버 관리가 필요합니다.

같은 와이파이에 연결된 친구는 호스트 PC의 사설 IP(예: `http://192.168.0.10:3000`)에 접속할 수 있습니다. Windows 방화벽 허용이 필요할 수 있습니다.

## 3. 게임 규칙

- **인원:** 2–12명 참가 가능. 호스트도 참가자로 계산됩니다. 관전자는 프로그램상 수 제한이 없으나 실제 동시접속 수는 호스트 PC 성능, 네트워크, 터널 서비스의 제한을 받습니다.
- **좌석:** 화면상 시계 방향 순서로 배치됩니다. 내가 입력한 주제는 **바로 다음(시계 방향)에 앉은 사람**에게 배정됩니다. 자기 주제는 서버에서 본인에게 공개하지 않습니다.
- **대기실:** 각 참가자가 오른쪽 사람의 주제를 1개씩 작성합니다. 모두 입력하고 온라인 상태라면 호스트가 게임을 시작합니다.
- **진행 순서:** 처음 순서는 무작위이며 이후 시계 방향으로 돌아갑니다. 정답을 맞힌 사람은 다음 턴부터 건너뜁니다.
- **질문:** 자기 차례에 질문을 누르고 질문을 말하거나 텍스트로 입력합니다. **[확인]**을 누르면 다음 사람 차례입니다. 답변은 다른 참가자와 음성채팅으로 진행할 수 있습니다.
- **정답:** 자기 차례에 정답 시도 버튼을 누르고 말하거나 텍스트를 입력합니다. **시도자를 제외한 온라인 참가자 전원**이 정답/오답 중 하나를 투표합니다. 정답표가 대상자의 **엄격한 과반수**를 얻으면 성공합니다. 오답 과반수(또는 전원 투표 후 정답 과반수 미달)이면 실패, 별도 점수 없이 다음 턴입니다. 관전자는 투표할 수 없습니다.
- **점수:** 해당 판 1등 정답자 100점 / 2등 80점 / 3등 60점. 각 판 점수는 누적됩니다.
- **라운드 종료:** 3번째 정답자가 나오면 자동 종료되어 새로운 주제 입력 단계로 돌아갑니다. **2인 게임이라면 두 사람 모두 정답 시 종료**됩니다. 누적 점수와 최근 결과는 남습니다.
- **호스트 기능:** 게임 시작, 자리에서 참가자 내보내기(대기실만), 진행이 멈추면 턴 넘기기, 판 강제 종료.
- **관전:** 참가자 슬롯을 차지하지 않으며 투표 불가. 관전자에게 주제는 기본 가림, 선택 시 '스포일러 보기' 가능.

## 4. 주의사항

- 같은 사람이 새 탭을 열어 중복 참가할 필요가 없어요. **같은 브라우저에서 방 링크를 다시 열면 입장 정보를 복구**합니다.
- 화면에서 '나가기'만 누르면 참가자 자리는 그대로 남고 오프라인 표시됩니다. 호스트는 대기실에서 그 자리를 내보낼 수 있습니다.
- 점수·지난 결과·방 정보는 호스트 PC의 **`data/rooms.json`**에 저장되어 재실행 후에도 남습니다. 이 파일에는 방 입장용 비밀 토큰도 있으니 **다른 사람에게 공유하지 마세요**.
- 다른 사람이 호스트 PC를 종료하면 게임이 중단됩니다. 호스트 PC의 업로드 속도와 메모리에 따라 실제 관전 인원은 달라집니다.
- 현재 버전에는 음성/영상 채팅이 없습니다. 질문과 답변은 화면에 입력하거나 **Discord 등 음성채팅과 함께** 이용하세요.
- 인터넷에 주소를 공개하지 말고 아는 사람들에게만 공유하세요. 공개 운영용 로그인, 스팸 방지, 고급 운영자 권한은 아직 포함되어 있지 않습니다.

## 파일 구조

```text
yangsechan-game/
├─ server.js             호스트 웹서버 / 룸 상태 / 투표 판정 / WebSocket
├─ package.json          Node.js 실행 정보 (추가 의존성 없음)
├─ start_windows.bat     Windows 원클릭 실행
├─ start_tunnel_windows.bat 인터넷 공유용 터널 도우미
├─ public/
│  ├─ index.html         화면
│  ├─ style.css          반응형 스타일
│  ├─ app.js             사용자 인터페이스
│  └─ favicon.svg
└─ data/
   └─ rooms.json        실행하면 자동 생성됨
```

## 🌐 설치 없이 웹사이트로 배포하기

프로젝트의 **[README_WEB.md](README_WEB.md)** 를 따라 Render에 배포하면 친구들은 웹주소로 들어와 참가/관전할 수 있습니다. 무료 호스팅에서는 점수 데이터가 재시작 시 초기화될 수 있습니다.
